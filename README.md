# Warhammer Archive

Локальное приложение для каталогизации, поиска и последующего RAG-анализа
пользовательской библиотеки PDF. Исходные книги, OCR-текст, поисковые индексы и
модели хранятся только на компьютере пользователя и не входят в репозиторий.

## Текущий этап: v0.1 Library Auditor

Первая версия выполняет безопасный аудит библиотеки без OCR и без изменения
исходных файлов:

- рекурсивно находит PDF;
- считает файлы, страницы и объём коллекции;
- проверяет наличие извлекаемого текстового слоя;
- отмечает страницы-кандидаты на OCR;
- различает текстовые, сканированные и смешанные документы;
- находит точные дубликаты файлов по SHA-256;
- фиксирует зашифрованные и повреждённые PDF;
- сохраняет отчёт без полного текста книг.

## Быстрый запуск на Windows

Требуется Python 3.11 или новее.

```powershell
py -m venv .venv
.venv\Scripts\activate
python -m pip install -e .
warhammer-archive audit "D:\Warhammer Library" --output "D:\Warhammer Archive Data\audit"
```

Без установки команды проект можно запустить так:

```powershell
python -m warhammer_archive audit "D:\Warhammer Library" --output ".\audit-report"
```

Аудитор создаёт:

- `summary.json` — общую статистику коллекции;
- `documents.jsonl` — по одной записи на каждый PDF, включая постраничные
  метрики, но без извлечённого текста.

Повторный запуск атомарно заменяет только эти два отчёта. Книги никогда не
изменяются.

## План развития

1. **v0.1 — Library Auditor:** инвентаризация и классификация PDF.
2. **v0.2 — Extractor:** текстовый слой, layout-анализ и OCR.
3. **v0.3 — Search:** полнотекстовый и семантический поиск.
4. **v0.4 — RAG:** ответы только по найденным источникам с указанием страниц.
5. **v0.5 — Desktop:** интерфейс, просмотр источников и установщик.

Архитектурные решения описаны в [`docs/architecture.md`](docs/architecture.md).

## Статус проекта

Проект находится на раннем этапе разработки. Визуальное оформление, логотипы и
тематические ассеты будут добавлены после стабилизации ядра и форматов данных.

Warhammer Archive — неофициальный фанатский проект и не связан с Games Workshop.
Репозиторий не распространяет книги, журналы или кодексы; пользователь добавляет
собственные источники самостоятельно.
